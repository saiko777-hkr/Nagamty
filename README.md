# نغمتي

مكتبة موسيقى عربية متجاوبة. الزوار يقدروا يبحثوا في الأغاني اللي أضفتها أنت، يشغّلوها من الموقع، أو يحمّلوها على أجهزتهم. الموقع لا يسمح للزوار برفع أغاني.

تتضمن الواجهة قوائم تشغيل ومفضلة وترتيبًا حسب مرات الاستماع، بالإضافة إلى التشغيل التالي والسابق والعشوائي والتكرار. يعمل البحث في اسم الأغنية والفنان والألبوم والنوع.

## تشغيل ونشر الموقع

افتح `index.html` في المتصفح، أو ارفع ملفات الموقع إلى استضافة مواقع ثابتة. لا يحتاج الموقع إلى تثبيت حزم أو إعداد خادم.

## إضافة أغنية للمكتبة

1. أنشئ مجلدًا باسم `music` بجانب `index.html`.
2. ضع فيه ملف MP3 وصورة الغلاف إن وجدت.
3. أضف بيانات الأغنية إلى مصفوفة `window.MUSIC_LIBRARY` في `songs.js`:

```js
window.MUSIC_LIBRARY = [
  {
    title: "اسم الأغنية",
    artist: "اسم الفنان",
    album: "اسم الألبوم",
    src: "music/song.mp3",
    genre: "عربي",
    coverImage: "covers/song.jpg",
    cover: "linear-gradient(135deg, #7658aa, #d081ae)"
  }
];
```

`src` هو رابط ملف MP3 الذي يستخدمه المشغل وزر التنزيل. `coverImage` اختياري لمسار صورة الغلاف، و`album` اختياري لاسم الألبوم. عند غياب الصورة يعرض الموقع غلافًا لونيًا تلقائيًا.

4. ارفع `index.html` و`styles.css` و`app.js` و`songs.js` ومجلد `music` وأي مجلد صور إلى الاستضافة، مع الحفاظ على المسارات. أعد الرفع كلما أضفت أغاني.

المفضلة ومرات الاستماع وقوائم التشغيل تُحفظ محليًا في متصفح كل زائر؛ لا يوجد حساب أو قاعدة بيانات مشتركة، ولا تنتقل هذه البيانات بين أجهزته. لهذا فإن «الأكثر استماعًا» يعكس استخدام هذا الجهاز فقط.

لضمان عمل التشغيل والتنزيل، استضف ملفات الأغاني على نفس نطاق الموقع، واختبر رابط ملف MP3 بعد النشر. أضف فقط الملفات التي تملك حق نشرها ومشاركتها للتنزيل.
