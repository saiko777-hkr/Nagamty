# نغمتي

مكتبة موسيقى عربية متجاوبة. الزوار يقدروا يبحثوا في الأغاني اللي أضفتها أنت، يشغّلوها من الموقع، أو يحمّلوها على أجهزتهم. الموقع لا يسمح للزوار برفع أغاني.

تتضمن الواجهة قوائم تشغيل ومفضلة وسجل آخر 20 أغنية بدأ تشغيلها، وترتيبًا حسب مرات الاستماع، بالإضافة إلى التشغيل التالي والسابق والعشوائي والتكرار. يعمل البحث في اسم الأغنية والفنان والألبوم والنوع.

## تشغيل ونشر الموقع

افتح `index.html` في المتصفح، أو ارفع ملفات الموقع إلى استضافة مواقع ثابتة. لا يحتاج الموقع إلى تثبيت حزم أو إعداد خادم.

تثبيت الموقع كأنه تطبيق يحتاج نشره على رابط HTTPS. ارفع `manifest.webmanifest` و`service-worker.js` وملف `pwa.js` ومجلد `icons` مع بقية الملفات. زر «تثبيت التطبيق» يعرض طلب التثبيت في المتصفحات المدعومة أو خطوات الإضافة اليدوية. على Android افتح الموقع في Chrome واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». على iPhone/iPad افتح الموقع في Safari، واضغط «مشاركة»، ثم «إضافة إلى الشاشة الرئيسية». فتح الموقع مباشرة كملف `index.html` لا يدعم التثبيت أو العمل دون اتصال.

يخزّن عامل الخدمة ملفات واجهة الموقع لتفتح دون اتصال بعد أول زيارة ناجحة. ملفات MP3 لا تُخزّن دون اتصال تلقائيًا؛ يلزم اتصال بالإنترنت لتشغيلها من الموقع.

## إضافة أغنية للمكتبة

1. أنشئ مجلدًا باسم `music` بجانب `index.html`.
2. ضع فيه ملف MP3 وصورة الغلاف إن وجدت.
3. أضف بيانات الأغنية إلى مصفوفة `window.MUSIC_LIBRARY` في `songs.js`:

```js
window.MUSIC_LIBRARY = [
  {
    title: "اسم الأغنية",
    artist: "اسم الفنان",
    album: "اسم الألبوم",
    src: "music/song.mp3",
    genre: "عربي",
    coverImage: "covers/song.jpg",
    cover: "linear-gradient(135deg, #7658aa, #d081ae)"
  }
];
```

`src` هو رابط ملف MP3 الذي يستخدمه المشغل وزر التنزيل. `coverImage` اختياري لمسار صورة الغلاف، و`album` اختياري لاسم الألبوم. عند غياب الصورة يعرض الموقع غلافًا لونيًا تلقائيًا.

4. ارفع `index.html` و`styles.css` و`app.js` و`songs.js` ومجلد `music` وأي مجلد صور إلى الاستضافة، مع الحفاظ على المسارات. أعد الرفع كلما أضفت أغاني.

## رفع أغنية إلى GitHub من المتصفح

1. افتح مستودع الموقع على GitHub وسجّل الدخول.
2. افتح مجلد `music` داخل المستودع. إذا لم يكن موجودًا، أنشئ ملفًا داخله أولًا باسم `music/.gitkeep` من **Add file** ثم **Create new file**؛ GitHub لا يحتفظ بالمجلدات الفارغة.
3. من داخل مجلد `music` اختر **Add file** ثم **Upload files**.
4. اسحب ملف MP3 من جهازك إلى الصفحة، وانتظر اكتمال الرفع، ثم اضغط **Commit changes**.
5. تأكد أن اسم الملف ومكانه يطابقان المسار في `songs.js`. للأغنية الحالية مثلًا يجب أن يكون الملف في `music/mahragan-hagmet-shorta-kabast.mp3`.
6. بعد رفع الملف، ارفع أي تعديل على `songs.js`، ثم انتظر تحديث الاستضافة واختبر رابط الأغنية.

ارفع ملفات المشروع الأخرى بنفس الطريقة إلى جذر المستودع، مع الحفاظ على أسماء الملفات والمجلدات. حد GitHub لرفع الملفات من المتصفح هو 25 MiB لكل ملف؛ ملف الأغنية الحالي أصغر من ذلك.

المفضلة ومرات الاستماع وقوائم التشغيل وسجل آخر 20 أغنية تُحفظ محليًا في متصفح كل زائر؛ لا يوجد حساب أو قاعدة بيانات مشتركة، ولا تنتقل هذه البيانات بين أجهزته. لهذا فإن «الأكثر استماعًا» يعكس استخدام هذا الجهاز فقط.

لضمان عمل التشغيل والتنزيل، استضف ملفات الأغاني على نفس نطاق الموقع، واختبر رابط ملف MP3 بعد النشر. أضف فقط الملفات التي تملك حق نشرها ومشاركتها للتنزيل.
